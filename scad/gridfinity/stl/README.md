# Gridfinity STL files

Pre-rendered bins and baseplates. Tubs are no longer stored here: build one with `python3 hutchfinity.py` at the repository root, which also builds any bin or baseplate size.

`scad/gridfinity/dental/build-stl.sh` still lists the retired tubs because the bin catalog pins that file by hash. Ignore its tub output.

Use `baseplate-mini.stl`, `baseplate-regular.stl`, and `baseplate-mega.stl` for new baseplates.

## Deprecated cropped baseplates

The following files are retained for historical comparison only and are not part of the current print set. Do not use them for new prints:

- `baseplate-mini-cropped.stl`
- `baseplate-regular-cropped.stl`
- `baseplate-mega-cropped.stl`
