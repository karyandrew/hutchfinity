# Agent Guidance

## Project

Hutchfinity is a public OpenSCAD project for a modular drawer chest system built around Gridfinity Extended at half pitch.

The core parts are tubs, casings, handles, and pegs. Keep guidance and documentation general-purpose unless a task explicitly scopes a public, domain-neutral exception.

## Public Safety

Treat every committed file, branch name, commit message, PR title, and PR body as public.

Do not add:

- Personal names, contact details, local paths, or machine/runtime details
- Private-repo references or private workflow assumptions
- Domain-specific deployment context, storage categories, labels, colors, or operating procedures
- License decisions or license-policy claims

When public-safety and functional guidance conflict, keep the function by rewriting it in public-safe terms rather than preserving sensitive wording.

## Working Rules

- Check the working tree before editing.
- Keep changes narrowly scoped to the requested files and behavior.
- Do not modify SCAD or STL files unless the task explicitly asks for geometry or generated-output changes.
- Do not backfill issue frontmatter or mutate GitHub issues unless the user explicitly asks.
- Do not commit, push, or open a PR without explicit authorization.
